Bond Desk is a small, complete bond market running on Hedera testnet. Nothing on it is real money. The bonds, the
USDC and the collateral are test assets, and every transaction is public on HashScan.

It has four parts:

<CardGroup cols={2}>
  <Card title="Bonds issued through ATS" icon="file-certificate" href="/how-it-works/bond-token">
    Each bond is a security token created by Hedera's Asset Tokenization Studio. The token carries its own KYC
    list, freeze list and transfer rules.
  </Card>
  <Card title="An order book that asks the token first" icon="scale-balanced" href="/how-it-works/order-book">
    Before a trade settles, the market asks the bond token whether the transfer is allowed. If the token says no,
    nothing moves.
  </Card>
  <Card title="Coupons paid by the network" icon="calendar-check" href="/how-it-works/coupons">
    The Hedera Schedule Service fires each coupon payment on time. The contract pays, and the executed call
    schedules the next one.
  </Card>
  <Card title="Collateral watched from inside an enclave" icon="shield-check" href="/how-it-works/risk">
    A Chainlink CRE confidential workflow reads the collateral coverage, compares it with thresholds nobody on
    chain can read, and signs a verdict that can freeze trading.
  </Card>
</CardGroup>

## The one idea to keep

**The policy is private, the verdict is public and verifiable.** The thresholds that decide a freeze never leave
the enclave. Every verdict the enclave signs lands on chain with the coverage it saw, so anyone can check that a
freeze was justified without learning where the line sits.
