# deployments/

`testnet.json` is written by `contracts/script/Deploy.s.sol` (`DEPLOYMENTS_OUT` overrides the path, but it must stay under this directory: `foundry.toml` grants `fs_permissions` here only). Flat shape: `chainId`, `deployer`, `block`, the six desk contracts (`registry`, `oracle`, `vault`, `market`, `lifecycle`, `riskGate`), `settlement` (MockUSDC when `SETTLEMENT` was empty), the ATS `token`, `bondId`, the Chainlink `feed`, the risk `signer`, the first coupon `schedule` (`run()` can only write forge's local mock answer; `forge script contracts/script/Deploy.s.sol:Deploy --sig "patchSchedule()" --rpc-url hedera`, run right after the broadcast, overwrites it with the on-chain HSS address that `docs/DEMO.md` and `harness/scripts/validate-schedule.sh` use), `wallets{issuer, investorKyc1, investorKyc2, investorNoKyc}` and `args{registry, oracle, vault, market, lifecycle, riskGate[, settlement]}` — the abi-encoded constructor args `contracts/script/verify.sh` passes to Sourcify. `contracts/script/Demo.s.sol` (`DEPLOYMENTS_FILE`), `api/` and `relayer/` read the same file.
